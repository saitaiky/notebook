# Reference

This folder stores private source material for future documentation and blog posts.

## What belongs here

- raw imports
- course notes and transcripts
- archive material
- drafting inputs that should not be published on the site

## What does not belong here

- polished docs that should appear on the site
- dated blog posts that should be published

## Publishing boundary

- Put public documentation in `docs/**`.
- Put public blog posts in `blog/**`.
- Keep source-only material in `reference/**`.

If a note is mainly used to help write a future page or post, keep it here instead of under `docs/**`.
