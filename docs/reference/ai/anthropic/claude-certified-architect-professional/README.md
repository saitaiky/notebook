[Claude Certified Architect — Professional Prep Course](https://anthropic-partners.skilljar.com/path/claude-certified-architect-professional)

## Study-note workflow

For each lesson, open the relevant course page in Chrome and ask Codex to process the current module. Each Markdown page
should:

- follow the module's visible structure and ordering;
- explain the concepts faithfully in detailed study-note form;
- retain short essential definitions, examples, and code where needed;
- distinguish course material from added study aids or clarifications;
- avoid changing course progress, answers, or other browser state; and
- avoid reproducing the proprietary course as a verbatim transcript.
