## How to use this pack

1. Read one chapter and reproduce its decision rules from memory.
2. Take the matching exam closed-notes in 60 minutes.
3. Open the concealed key only after recording every answer.
4. Log weak topics, revisit the relevant section, and retry with a fresh answer sheet.

These pages follow the course's concepts and ordering in detailed, paraphrased study-note form. They are not verbatim
course transcripts. Product names, model IDs, prices, limits, beta status, and platform availability are time-sensitive;
verify them in current Anthropic and cloud-provider documentation before using them in production.

## Exam-agent contract

Each exam has 30 one-point multiple-choice questions and five four-point scenarios. The answer key and rubrics are
inside collapsed `<details>` blocks. An exam agent should present questions without revealing those blocks, accept a
complete answer sheet, score against the key, explain missed decision rules, and update only the learner's review log.
