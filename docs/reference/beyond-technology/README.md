# Beyond Technology source notes

This directory contains personal study material and drafting inputs that are not part of the public Docusaurus site.

## Publication boundary

- `arts/` contains unfinished practice notes and source links for future cultural guides.
- `career/` contains notes taken from professional-development courses.
- `home/` contains personal checklists and decision aids.
- `language/` contains language-learning notes intended for personal study.

When one of these notes develops into a coherent essay or reader-facing guide, curate a new page under `docs/other/**`. Do not move raw material into the public tree merely to make it discoverable.
