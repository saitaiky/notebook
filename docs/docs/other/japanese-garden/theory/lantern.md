## 石燈籠的結構和設計

### 日本園林中石燈籠存在的理由

現代的石燈籠已經成為園林中非常普遍的裝飾，以至於提到“石燈籠”，大多數人腦海中立即會浮現出它的形象。然而，石燈籠在日本園林歷史中的應用並沒有那麼久遠。

石燈籠起源於中國，隨佛教一起傳到日本，最初作為佛前的供燈被放置在神社和寺院內。據說千利休（せんのりきゅう）是第一位將石燈籠引入園林的人，他被石燈籠中清晨的余燼所感動，將這種景致的情趣作為晚間茶事的燈火帶入園林中。此後，因其低調的燈火和耐人尋味的造型，石燈籠也被用於除茶庭之外的其他類型園林中。

在充滿樹木和岩石等自然元素的園林中，石燈籠這種人工的造型不知不覺中吸引了觀賞者的眼球。石燈籠的存在是園林中的點睛之筆，成為園林中重要的裝飾物。

### 構成石燈籠的基本六元素

![](/img/other/garden/theory/masaki-horiuchi-37.png)

石燈籠基本上由六個元素構成，從上到下依次為寶珠、笠（燈頂）、火袋、中台（中坐）、竿（燈柱）、基礎（基石）。這六個元素全部具備的石燈籠稱為「基本型」，而省略了除火袋外其他元素的石燈籠稱為「變化型」。
- **寶珠**：石燈籠頂部的球狀部分，有單獨的寶珠和附有蓮花底座的寶珠兩種。
- **笠（燈頂）**：燈籠頂部的部分，邊緣大多向上卷曲。
- **火袋**：放置燈火的部分，是石燈籠最重要的元素，開口的部分稱為「點火口」。
- **中台（中坐）**：支撐火袋的部分，大多與底部的基礎造型方向相反。
- **竿（燈柱）**：支撐整個石燈籠的柱子，分為圓柱和方柱兩種，一般在燈柱的上、中、下三個部分附有竹節、二重帶不正米紋帶等節狀物。
- **基礎（基石）**：支撐竿的基石，又稱為「地輪」，基石的上部是反向放置的蓮花座，周圍大多有名為「格左問」的雕刻花紋。

:::info 構成石燈籠的基本六元素
- **寶珠**：頂部球狀部分
- **笠（燈頂）**：燈頂部分
- **火袋**：放置燈火的部分
- **中台（中坐）**：支撐火袋
- **竿（燈柱）**：支撐整體的柱子
- **基礎（基石）**：支撐竿的基石
:::

### 基本型石燈籠和變化型石燈籠

![](/img/other/garden/theory/masaki-horiuchi-3.jpg)

#### 大部分基本型石燈籠都是布施之物

基本型石燈籠具備所有的基本元素，原本幾乎都是向神社和寺院供奉的佛燈。從上方看，燈頂的形狀可以分為三角燈籠、四角燈籠、六角燈籠、八角燈籠和圓形燈籠。其中，以春日燈籠（かすがとうろう）為代表的六角燈籠最常見。基本型石燈籠的名稱一般是根據其最初所在的神社和寺院來命名的，如春日燈籠、平等院形燈籠（びょうどういんがたとうろう）和勸修寺形燈籠（かんしゅうじがたとうろう）等。

#### 由茶人發展而來的變化型石燈籠

變化型石燈籠幾乎都是在其開始用於園林造景後，由茶人們精心設計發展而來的園林裝飾物。

**無基座石燈籠、埋地石燈籠**：無基石部分，支柱直接插於地下。著名的例子是織部燈籠（おりべとうろう），其支柱上部還有拉丁十字，中間刻有英文字母，下部刻有聖母瑪利亞像的浮雕，因此也被稱為「吉利支丹石燈籠」（きりしたんいしとうろう）。還有水螢形燈籠（みずほたるがたとうろう）、曼殊院形燈籠（まんしゅいんがたとうろう）等。

**雪見燈籠**：無基石部分，下部的支柱變形為支架型，多置於水池和溪流邊。金澤兼六園（かなざわ けんろくえん）的微輕燈籠（ことじとうろう）也是雪見燈籠的一種。

**可移動石燈籠、放置式石燈籠**：無支柱和基石，將中坐以上的部分直接置於岩石上的燈籠，如岬石燈籠（みさきとうろう）、三光燈籠（さんこうとうろう）和源自京都桂離宮（かつらりきゅう）的毬石燈籠（まりいしとうろう）。

**野面石燈籠**：幾乎全部由未經打磨的天然石塊製作。

**其他類型**：還有京都修學院離宮（しゅうがくいんりきゅう）的袖形燈籠（そでがたとうろう）、京都真如院（しんにょいん）的瓜子形燈籠（うりがたとうろう）等。

:::info 變化型石燈籠
- **無基座石燈籠、埋地石燈籠**：支柱直接插於地下
- **雪見燈籠**：下部支柱變形為支架型
- **可移動石燈籠、放置式石燈籠**：無支柱和基石，直接置於岩石上
- **野面石燈籠**：未經打磨的天然石塊製作
:::

### 石燈籠的基本配置法

![](/img/other/garden/theory/masaki-horiuchi-38.png)

石燈籠原本的作用是夜間照明，一般置於園路的旁邊、拐角、盡頭、樹下稍暗處以及蹲踞（つくばい）的後面等需要光照的地方。雖然現在石燈籠幾乎不再用於照明，但仍被置於這些地方，成為重要的裝飾物。

#### 基本配置原則

1. **園路旁**：無基座石燈籠、埋地式燈籠等小型石燈籠低置於園路旁，作為腳下照明。
2. **拐角和盡頭**：置於園路的拐角和盡頭處，像燈塔一樣具有吸引人前行的效果。
3. **樹蔭下**：置於樹蔭下的石燈籠通過與樹木達到平衡和枝葉遮擋，營造出若隱若現的效果。

#### 石燈籠不能作為園林主景

配置石燈籠時，應注意不要讓其在園林中過於顯眼。例如，將石燈籠放置於園林中心時，石燈籠會過於顯眼，景色會變得單調，無法表現園林幽深之景。石燈籠和園林大小不相符也會破壞景觀。在一定的視線範圍內，不能放置兩盞以上的石燈籠。除了

非常簡樸的坪庭（つぼにわ）外，石燈籠不能作為園林主景，其作用是適當地修飾景色，使景觀從整體上達到協調。

:::info 石燈籠的基本配置
- **園路旁**：小型石燈籠作為腳下照明
- **拐角和盡頭**：吸引人前行的效果
- **樹蔭下**：若隱若現的效果
:::

### 組裝石燈籠的關鍵是保證穩定性

![](/img/other/garden/theory/masaki-horiuchi-39.png)

組裝石燈籠的順序是從最下面的基石開始，依次為燈柱、中坐、火袋、燈項、寶珠。每組裝一個部分，就需要確認是否水平和垂直，在保證穩定性的基礎上進行組裝。大部分石燈籠文物只有燈項、火袋和中坐，在2011年東日本大地震（ひがしにほんおおじしん）等大規模地震中，有相當數量的石燈籠文物已經被毀壞。但現在製作的石燈籠大部分都採取了防倒措施，即在各部分的接合處凿榫卯（そんぼう），四凸部分相嵌合的方式，即使發生小規模地震石燈籠也不會倒塌。

:::info 組裝石燈籠的關鍵
- **組裝順序**：基石、燈柱、中坐、火袋、燈項、寶珠
- **確認穩定性**：是否水平和垂直
- **防倒措施**：接合處凿榫卯
:::
