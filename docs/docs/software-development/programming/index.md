Programming is the implementation layer of the software-development path. Start with the concepts that transfer between
languages, then choose the language-specific notes needed for a project. The goal is not to memorise syntax; it is to
understand execution, data transformation, complexity, and the trade-offs that make code maintainable.

## Core foundations

- [Big-O complexity](/software-development/programming/big-o/) gives a vocabulary for comparing resource growth.
- [Programming paradigms](/software-development/programming/paradigm-of-programming/) compares ways to structure
  behaviour and state.
- [Static, dynamic, strong, and weak typing](/software-development/programming/strong-weak-dynamic-static/) separates
  concepts that are often conflated.
- [Floating-point and decimal values](/software-development/programming/float-decimal/) explains why representation
  matters in financial and scientific code.
- [Extreme programming](/software-development/programming/extreme-programming/) connects implementation choices to short
  feedback loops and maintainability.

## Language paths

- **[JavaScript](/software-development/programming/javascript/):** functions, promises, async execution, bundling, and
  everyday language features.
- **[Node.js](/software-development/programming/nodejs/):** server-side JavaScript, Express, and package construction.
- **[Python](/software-development/programming/python/):** modules, environments, async execution, debugging, iterators,
  and functional techniques.
- **[React](/software-development/programming/react/hydration/):** hydration, state/effects, and reference or
  memoisation hooks.
- **[Rust](/software-development/programming/rust/):** a starting point for systems-oriented, memory-safe programming.

## Continue into delivery and cloud

Once an implementation works locally, continue with [version control](/software-development/version-control/) and the
[software delivery lifecycle](/software-development/devops/). For managed runtimes, compare
[AWS Lambda](/aws/compute/lambda/), [EC2](/aws/compute/ec2/), and [ECS](/aws/compute/ecs-ecr/) against the process and
operational model your program needs.
